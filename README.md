# Deep Noise

WebAssembly 음향 엔진으로 깊은 저음과 노이즈, 그리고 샤워·폭포·선풍기·빗소리·시냇물·바람·여름밤·기차·벽난로 같은 풍경을 실시간으로 만들어 재생하는 웹 플레이어입니다.

**▶ 바로 듣기: https://slow0704-eng.github.io/deep-noise/**

`index.html` 하나에 엔진(WASM, base64 인라인)과 UI가 모두 들어 있어 브라우저에서 바로 열 수 있습니다.
`file://`로 열었을 때 소리가 나지 않으면 `python -m http.server`로 띄운 뒤 `http://localhost:8000`에서 여세요.

## 기능
- 프리셋 13종: 깊은 우주 · 샤워 물줄기 · 폭포 · 선풍기 · 바다 파도 · 빗소리 · 시냇물 · 바람 · 여름밤 · 기차 · 벽난로 · 비행기 객실 · 집중
  - 화이트·핑크·브라운 노이즈는 이름 대신 그 색에 가장 가까운 실제 소리로 보여 준다: 샤워 물줄기(화이트) · 폭포(핑크) · 선풍기(브라운).
    셋 다 실제 녹음의 소리 색에 맞춘 배경이다(아래 레퍼런스 파이프라인)
- 레이어: 밝은 쏴—(White) · 부드러운 물소리(Pink) · 묵직한 웅—(Brown) · Deep 서브베이스(25–120Hz, 모노) · 장면 사건(빗방울·레일 덜컹·장작 타닥·물방울·돌풍과 휘파람·풀벌레)
- 노이즈 색 전환(밝게 · 부드럽게 · 묵직하게): White · Pink · Brown을 레벨을 유지한 채 클릭 없이 크로스페이드
- 필터: 로우패스·하이패스 컷오프와 Q(공진), 로우패스 기울기 12↔24 dB/oct — TPT 상태변수필터(바이쿼드와 같은 2차 응답, 실시간 변조에 안정적), Q에 따른 레벨 보정
- 엔벨로프: 엔진 내부 샘플 단위 페이드 인/아웃(5ms–10초), 볼륨은 블록 안에서 샘플 단위 보간
- 음색: 베이스 부스트(최대 +14dB), Air, 웜스(새츄레이션) / 공간: 스테레오 폭, 파도 스웰(깊이·속도)
- 실시간 스펙트럼, 슬립 타이머(마지막 1분 페이드아웃), 설정 자동 저장, Space 재생/정지

화면은 노이즈 재생이 중심이고, 장면 프리셋을 고르면 그 장면의 조절(빈도·속도·음높이 등)이
프리셋 아래에 열린다(샤워·폭포·선풍기는 조절 없이 설명과 수치만). 레퍼런스 분석 수치와 출처는 그 안의 **어떻게 만들었나요**를 펼쳐야 보인다.
프리셋 아이콘은 [Lucide](https://lucide.dev)(ISC 라이선스)의 선 아이콘을 인라인 SVG로 넣고 프리셋마다 그라데이션 타일을 씌웠다.

## 장면 엔진
Andy Farnell 《Designing Sound》의 절차적 오디오 방식: 지속적인 배경(베드) + 확률적으로 도착하는 개별 사건.
녹음을 반복 재생하지 않아 같은 순간이 두 번 오지 않는다.

- **배경(베드)**: 화이트·핑크·브라운 노이즈 + 딥 서브베이스, 로우패스·하이패스·Air로 색을 맞춤
- **이벤트 보이스 풀**: 장면의 사건은 같은 보이스(노이즈 임펄스 → 공진 밴드패스, 또는 사인 모드)를 쓰고 스케줄러만 다르다.
  32개를 WASM 선형 메모리에 고정 할당해 라운드로빈으로 재사용 — 오디오 스레드 할당 0
  - 임펄스 엔벨로프: 0.25 ms 어택 스무딩 + 지수 감쇠 — 네모난 시작·끝이 만드는 '틱'을 없앤다
  - 스테레오 디코릴레이션: L/R이 서로 독립된 노이즈로 울려 공진 위상이 무작위, 작게 들리는 쪽은 2–10 ms 늦게 시작
- **빗소리**: 푸아송 과정. 다음 방울까지의 간격을 지수분포 `−ln(1−U)·sr/λ`로 샘플 단위로 뽑는다.
  방울마다 크기(U² 분포, 클수록 낮게), 종류('톡' 유리: Q 6–20, 2–6 kHz / '툭' 잎: Q 1.2–3), 위치를 무작위로 정한다.
  감쇠는 2–15 ms. 잔빗소리는 채널마다 독립된 촘촘한 푸아송 과정(λ의 수십 배)의 3 ms 버스트
- **기차**: 객차 한 량의 대차 2개 × 차축 2개가 레일 이음매(주기 T)를 차례로 지난다.
  25 m 레일·차축 간격 2.5 m·대차 간격 17.5 m → 타격 위치 0, 0.1T, 0.7T, 0.8T('덜컹 … 덜컹').
  타격마다 저역 '쿵'(차체 충격, 30 ms)과 '덩'(바퀴–레일, 3 ms)을 함께 울리고, 주기는 ±4% 안에서 천천히 흔들린다
- **벽난로**: 군집 푸아송(Neyman–Scott) — 군집 도착은 푸아송, 군집 안 타닥은 평균 12 ms 지수 간격.
  타닥은 U³ 세기 분포·0.6–2 ms 감쇠, 가끔 낮고 굵은 '펑'. 불꽃 일렁임은 2.5 Hz로 평활한 노이즈(분산 1로 정규화)가
  베드 세기와 타닥 빈도를 함께 흔든다
- **시냇물**: 물 흐름의 넓은 쏴— 위에 푸아송 도착 공기방울. 보이스의 사인 모드로 울리고(물속 공기방울의 Minnaert 공명),
  터지며 반지름이 줄어 음높이가 감쇠 시간마다 (1 + 상승)배로 지수적으로 올라간다(van den Doel의 방울 모델) — '또르륵'.
  크기는 U² 분포(작은 방울이 많다), 작을수록 높고 짧다(감쇠 ≈ 9 ms × √(700/f), 3–25 ms)
- **바람**: 불꽃 일렁임과 같은 2단 평활 노이즈를 ≈0.05–0.5 Hz로 느리게 만든 무작위 돌풍이 베드 세기를 흔든다(규칙적인 스웰 LFO와 달리
  매번 다르게 분다). 채널 독립 노이즈 → 공진 BP(Q 5)의 휘파람은 돌풍의 제곱으로 커지고 ±0.5 oct 높아진다
- **여름밤**: 풀벌레 세 마리가 각자의 주기(×1, ×1.17, ×0.86, 울음마다 ±8%)로 울음 = 사인 펄스(감쇠 6 ms) 묶음을 반복한다.
  마리마다 음높이(×1, ×0.94, ×1.06)·자리·세기가 달라 서로 엇갈린다
- **타격음 버스 LP**: 사건 + 잔빗소리를 베드 LP와 같은 컷오프의 2차 LP로 한 번 더 감싸, 컷오프 위에서
  BP 스커트의 날카로운 고역이 베드보다 가파르게 떨어지도록 함
- **출력단**: 스테레오 링크 룩어헤드 피크 리미터(1.33 ms, −2 dBFS, 릴리스 ≈100 ms) → 소프트 니 클리퍼
  (0.9까지 무왜곡, 그 위는 tanh형으로 1.0에 접근). 사건이 겹친 순간 피크가 0 dBFS를 넘어 깨지지 않는다

### 레퍼런스 파이프라인
장면마다 같은 과정(배경만 있는 샤워·폭포·선풍기도): 유튜브 레퍼런스 선정 → 분석 JSON → 피팅 → 엔진 초기 파라미터 자동 바인딩 → 렌더 후 같은 분석기로 재검증.

```
python -m venv tools/.venv
tools/.venv/Scripts/activate          # macOS/Linux: source tools/.venv/bin/activate
pip install -r tools/requirements.txt  # librosa, numpy, scipy, yt-dlp (+ ffmpeg 필요)
npm install
npm run rain                           # 또는 npm run fire / npm run night ... — 아래 다섯 단계를 순서대로 실행
```

| 단계 | 명령 (`<장면>` = rain · train · fire · stream · wind · night · shower · waterfall · fan) | 하는 일 |
|---|---|---|
| 선정·수집 | `npm run <장면>:fetch` | `tools/select_reference.py --scene <장면>` — 장면별 검색어로 30개를 받아 메타정보로 평가(아래)하고 1위를 받는다. 스트림이 막힌 영상(HTTP 403)과 소리 상태가 나쁜 영상(너무 작은 녹음 RMS < −50 dBFS, 에너지 절반 이상이 30 Hz 아래인 마이크 바람 진동)은 다음 순위로 넘어간다. `tools/fetch_reference.py`가 원본 오디오를 받아 ffmpeg로 구간만 잘라 48 kHz WAV로 저장(`reference/`, 커밋 안 함) |
| 분석 | `npm run <장면>:analyze` | `tools/analyze_reference.py` — 스펙트럼 중심·롤오프·기울기·대역 에너지, RMS와 배경 일렁임, HPSS 타격 성분, 온셋 빈도(불감 시간 보정)·간격 분포, 타격 순간의 주파수 피크(40–300 / 300–1500 Hz, 중심), 100–1000 Hz 세기 엔벨로프의 자기상관 주기(기차 이음매), L/R 상관, 세기 엔벨로프 자기상관의 돌풍 속도, 2–10 kHz 스펙트럼 피크(풀벌레 울음 높이)와 그 대역의 울음 주기·펄스 빈도·점유율 → `src/profiles/<장면>.json` |
| 피팅 | `npm run <장면>:fit` | `tools/fit_reference.py <장면>` — 엔진 레이어를 하나씩 렌더해 1/3옥타브 대역 파워를 NNLS로 맞추고, 톤(LP 컷오프·Q·기울기, Air)·딥 서브 중심 주파수·사건 음높이를 격자 탐색, 타격 성분 비율이 같아지도록 사건 비중을 이분 탐색, 출력 레벨 정규화 → 프로파일의 `fit` 블록. 사건이 없거나 타격성이 아닌 장면(샤워·폭포·선풍기, 바람 휘파람, 풀벌레)은 사건 비중 탐색 없이 스펙트럼만 맞춘다. 새 장면(시냇물·바람·여름밤·샤워·폭포·선풍기)은 하이패스 컷오프도 격자에서 고른다(바람·폭포처럼 저역이 가파르게 꺾이는 녹음). 오차는 청감 가중(2–6 kHz 최대 3배)이고 2 kHz 위의 과잉은 2배로 본다. 피팅 렌더는 리미터가 개입하지 않게 마스터를 1/10로 낮춘다 |
| 빌드 | `npm run build` | `src/profiles/*.json` + `src/scene_model.js`(분석값 → 엔진 파라미터 매핑)를 페이지에 인라인 |
| 검증 | `npm run <장면>:verify` | `tools/render_scene.cjs <장면>`으로 엔진을 오프라인 렌더하고 같은 분석기로 레퍼런스와 비교한 표 출력 |

#### 레퍼런스 품질 선정
제목만 보고 고르면 조회수가 적거나 광고·음악·루프가 섞인 영상이 걸리기 쉽다. `select_reference.py`는
1. **하드 필터**: 분석 구간보다 짧은 영상, 라이브, 제목에 장면 단어(폭포·선풍기·cricket 등)가 없는 영상, 제목에 엔진에 없는 소리가 있는 영상 제외 — 빗소리는 천둥·음악·새소리,
   기차는 비·경적·역 안내방송·지하철, 벽난로는 비·바람·음악·고양이, 시냇물·폭포는 새소리·비, 여름밤은 개구리·부엉이·늪 등. "No Thunder", "NO RAIN NO MUSIC" 같은
   부정 표현은 지우고 판단한다.
2. **메타 점수**(후보 집단 안의 z-점수 가중합): 좋아요율 0.30(베이지안 평활), 조회수 0.20, 하루당 조회수 0.10,
   댓글율 0.10, 채널 구독자 0.10, 오디오 비트레이트 0.05
3. **댓글 신호** 0.15: 메타 상위 8개만 인기 댓글 60개를 받아 광고·루프·음악·볼륨 튐 같은 불만(감점 2배)과
   '진짜 같다·잠이 온다' 같은 반응을 센다.

순위표는 `reference/candidates_<장면>.json`에 남고, 메타데이터·댓글은 같은 날 다시 돌려도 결과가 같도록 `reference/.meta_cache/`에 캐시한다.
특정 영상을 쓰려면 `python tools/fetch_reference.py <URL> --start <초> --duration <초> -o reference/<장면>_ref.wav` 후 분석·피팅·빌드를 다시 실행하세요.

## 성능·안정성
- 오디오 스레드(`process`)는 할당 없음: WASM 메모리 뷰를 한 번만 만들어 재사용, 파라미터는 `Float32Array` 한 개로 모아 전송
- `latencyHint: 'playback'`로 하드웨어 버퍼를 크게 잡아 드롭아웃 방지
- 초기화: 기능 확인 → WASM 검증 → 워클릿 등록(blob → data URL 폴백) → `ready` 핸드셰이크(타임아웃 5초) → 그래프 연결. 실패하면 정리 후 다음 클릭에서 재시도
- 정지 시 페이드 아웃이 끝났다는 엔진 신호를 받은 뒤에만 `AudioContext`를 suspend
- 오프라인 렌더 기준 실시간의 약 50–80배 속도(장면 사건 포함)
